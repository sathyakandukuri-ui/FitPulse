# FitPulse — Fitness Progress Tracking System

**Track your fitness. Monitor your progress. Achieve your goals.**

FitPulse is a fitness progress tracking website designed to help users monitor their fitness journey in one place. It provides a dashboard for viewing fitness statistics, recording workouts, tracking body metrics, calculating BMI, and reviewing progress over time.

## 🎯 Overview

FitPulse aims to make fitness tracking simple, accessible, and organized. Users can record their workouts and body measurements, calculate their Body Mass Index (BMI), and view fitness activity and progress through a centralized dashboard.

The project is suitable for fitness enthusiasts, students, and individuals who want a convenient way to monitor their workout routines and personal fitness metrics.

## ✨ Features

- **Dashboard:** View a summary of fitness activity and important metrics.
- **Progress Tracking:** Record body metrics and review historical progress.
- **Workout Tracking:** Add and review workout records.
- **BMI Calculator:** Calculate Body Mass Index using height and weight.
- **Fitness Statistics:** View total workouts, exercise minutes, calories burned, and average water intake when data is available.
- **Progress Visualization:** View weight trends and exercise activity when records are available.
- **Quick Actions:** Access common fitness tracking functions directly from the dashboard.
- **Navigation:** Navigate between Dashboard, Progress, Workouts, and BMI Calculator.
- **Logout:** Access the logout control from the dashboard.

*Note: Available functionality depends on the current implementation and configuration of the website.*

## 📊 Dashboard
